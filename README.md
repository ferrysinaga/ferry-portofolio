# ⚡ Ferry's Space – Neo-Brutalist Personal Portfolio

Sebuah aplikasi web portofolio dinamis yang memadukan desain *neo-brutalist* yang berani dengan arsitektur *backend* yang tangguh. Proyek ini tidak hanya berfungsi sebagai etalase digital untuk proyek dan pencapaian, tetapi juga sebagai sistem manajemen konten (CMS) mandiri.

Antarmuka dibangun dengan pendekatan *card-based* bergaris luar tebal, bayangan padat, dan tipografi eksplisit, menghadirkan pengalaman visual yang tegas dan interaktif.

## ✨ Fitur Utama

*   **Custom Admin Panel:** CMS internal terintegrasi untuk mengelola Galeri, Proyek, Pengalaman, Pendidikan, dan Sertifikat secara *real-time* tanpa perlu menyentuh kode.
*   **Neo-Brutalist Aesthetics:** Desain UI/UX dengan kontras tinggi, struktur grid spasial yang jelas, dan elemen interaktif yang merespons secara instan.
*   **Secure Authentication:** Sistem login dan pembaruan kata sandi admin yang dilindungi sepenuhnya oleh otentikasi berbasis token.
*   **Fluid Animations:** Transisi mulus, efek *hover* dinamis, dan akordion interaktif yang ditenagai oleh animasi fisika (*spring*).
*   **Cloud Storage Integration:** Pengunggahan dan pengelolaan aset gambar (sertifikat, sampul proyek, galeri) secara langsung dari panel admin ke penyimpanan *cloud*.

## 🛠️ Tech Stack

*   **Frontend:** React, Next.js, Tailwind CSS
*   **Motion & UI:** Framer Motion
*   **Backend & Database:** Supabase (PostgreSQL)
*   **Authentication & Storage:** Supabase Auth & Supabase Storage
